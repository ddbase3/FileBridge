# FileBridge privacy and data lifecycle

**Source review: 2026-11-05.** This describes observable implementation behavior, not a deployment-specific privacy notice or a compliance claim.

FileBridge implements storage operations behind `Base3\ResourceFoundation\Api\IFileStorage` for local, FTP, WebDAV and disabled backends. The selected backend determines whether data is stored locally or transmitted to a remote host. FileBridge does not own authentication, user directories or business authorization; callers must authorize each operation. The `LocalManagedFileStorageService` accepts explicit owner group/name/mode values, hashes them to per-owner directory names and stores file bytes below its project-supplied root. It does not persist a second owner registry or new database table.

For the `chat.base3.de` composition, the root is `[directories] data`/`filemanager` and its local contents may include personal or sensitive uploaded documents. Local metadata includes filename, size and modification time. The FileManager upload sessions themselves belong to ClientStack and are staged by the project under the configured data directory in `filemanager/uploads`. FileBridge emits `ManagedFileStorageDeletingEvent` when an owner is deleted, then deletes the corresponding local subtree. `copyOwner` duplicates files to a different isolated owner directory. Ordinary file deletion removes the filesystem entry but does not guarantee secure erasure from storage media or backups.

`LocalFileStorage` rejects traversal and symlinks at the storage boundary and uses restrictive directory modes; the managed root writes Apache `Require all denied`. The web server MUST deny direct file access independently, especially when `.htaccess` is ignored. Credentials and network recipients for FTP/WebDAV cannot be determined from this standalone backend's deployment. Backups, retention, audit logs, client-side data collection and storage location outside the specified project remain host-dependent. The application/operator must document and enforce them.
